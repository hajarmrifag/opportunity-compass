# Hajar feature ownership

Hajar owns the user experience connecting opportunity discovery to follow-through:

- Dashboard search, goal starters, urgent deadlines and next pending action
- Guided live-search inputs, summaries, active filters and reset controls
- Three-item persistent comparison, including honest unknown and source states
- My Journey action plans, general suggested steps and user-created tasks
- Responsive, keyboard-accessible presentation and browser-local disclosure
- Opportunity Brief presentation and the browser-local affordability scenario editor

Existing boundaries remain unchanged: teammates own CV extraction, retrieval/source-quality improvements and eligibility verification. The affordability calculator is a pure typed review seam for the digital-finance teammate: it never edits sourced funding facts, converts currencies/periods, or treats missing values as zero.
